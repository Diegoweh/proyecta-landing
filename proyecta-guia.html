GTM + Meta Pixel + Thank You Page
DEV
▾
POR QUÉ ES CRÍTICO
Sin eventos de conversión, Meta Ads no puede optimizar. Cada peso se gasta "a ciegas". Esto BLOQUEA el lanzamiento de campañas.
// PASO 1: Instalar GTM Crear contenedor en tagmanager.google.com Instalar snippet en <head> del layout Next.js → ID: GTM-XXXXXXX (Zeta o Andrea crean la cuenta) // PASO 2: Dentro de GTM configurar: Tag 1: Meta Pixel Base Code → trigger: All Pages Tag 2: Meta Pixel Lead Event → trigger: Page View en /gracias Tag 3: GA4 Config → trigger: All Pages Tag 4: GA4 Event generate_lead → trigger: Page View en /gracias // PASO 3: Crear página /gracias Ruta: /gracias Contenido: mensaje de confirmación + "Te contactamos en menos de 24h" El form debe redirigir aquí después de submit exitoso // PASO 4: Verificación Meta Events Manager → Test Events → navegar al sitio GTM Preview Mode → confirmar disparo de tags → El media buyer (o Zeta) debe validar que el evento Lead aparezca
  • Crear contenedor GTM
  • Instalar GTM en layout de Next.js
  • Configurar Meta Pixel base (All Pages)
  • Crear página /gracias
  • Configurar evento Lead en Meta (trigger: /gracias)
  • Configurar GA4 base + evento generate_lead
  • Verificar dominio en Meta Business Suite
  • Validar con Meta Events Manager
